# 第四篇《烽火临界》CG卷封面

本目录只保存公开读者可见的**第31—40卷**WebP图片。正文、音频、人物设定等数据不在本目录。

上传文件名固定为：

```
volume-31.webp
volume-32.webp
volume-33.webp
volume-34.webp
volume-35.webp
volume-36.webp
volume-37.webp
volume-38.webp
volume-39.webp
volume-40.webp
```

对应卷名依次是：雪线夺路、逐榜烽烟、烽线争城、双城旗火、百旗城战、赤榜争锋、裂旗之城、边境夺旗、烽谷夺脉、烽关决战。

**上传方法：** 在 GitHub 的当前目录点击 `Add file → Upload files`，将上述十个 WebP 文件拖入，提交至 `main`。页面的 `assets/js/part04-cg-covers.js` 会在图片加载成功时自动替换原有文字艺术封面，若图片不存在或加载失败会保留原来的封面，不会出现空白。四篇独立防剧透与阅读进度保持不变。

**容量：** 各张已压缩为约 120–160 KB，总计约1.4 MB。请勿上传未压缩的原始大PNG。
