# V7 · 第一卷真实手机听书中心验收（独立测试环境）

## 最新边界
- 已有用户手动确认：真实 iPhone Safari 可直接打开 Release 的第8章 MP3，在线播放、暂停、拖动进度均正常。**这不是完整听书中心验收**。
- 第一卷11段 MP3 已在测试 Release；原 GitHub Pages MP3 完全保留。
- WebKit 自动化整合首次失败系 Playwright 不支持 `route.fulfill({status:302})`，需要使用真实 HTTP 302 修复后再运行。
- 目前公开正式站仍使用旧的 Pages MP3，不能把现有正式站的收听测试当作迁移后证据。

## 独立测试环境准备（未公开部署）
- 基于正式有声中心的页面、JS 和 CSS 制作预览，使用单独预览 URL/路径，确保不覆盖正式域名，不更改 Pages main，也不更改生产 JS。
- 仅第一卷音频指向已验证的 Release，其他卷要么使用原 URL 要么明确标注未迁移，不能引用不存在的链接。
- 预览用独立 localStorage 前缀或隔离 origin（最好使用不同 origin）；防止测试覆盖读者真实听书进度 `zs:audiobook:last:v1` 和 `zs:audiobook:positions:v1`。
- 在独立自动化 WebKit 测试通过、可公开访问的隔离预览环境已准备且可验证时，才要求真人操作完整听书中心。不能以本地 `127.0.0.1` 网址让其他手机访问。
- 不自动调用 ElevenLabs、不更改正文/防剧透、不新增收费服务。

## iPhone Safari + Android Chrome 手动验收标准
1. 在各自真实设备打开**经核实可访问的独立预览站点**，不要使用正式站代测。
2. 选择第一卷第8章，点击播放、暂停，再拖动至约30秒，播放数秒。
3. 关闭预览页面，重新打开同一地址，检查恢复播放位置（允许几秒误差）。
4. 打开“连续播放”，将第8章播放到末尾，检查是否正确进入第9章；若系统要求手动点击播放，记录而不是认定无声即成功。
5. 点击第9章下载，验证 MP3 能完整保存并播放。
6. 锁屏、切换后台、Wi-Fi/移动网络之间切换后，检查中断和恢复表现（可选择）。
7. 记录设备型号、系统版本、浏览器版本、日期、网络方式，以及播放/暂停/拖动/恢复/连播/下载逐项结果；失败时可以传不含隐私信息的截图。
